# LLM Council: shared deployment on a server (Docker + access gate)

Replaces the earlier host-service runbook. Not yet executed on a server. The stack was built and smoke-tested locally (UI returns 200, `/api/models` answers).

What runs: `council-api` (backend, not published) and `council-web` (nginx serving the UI and proxying `/api/`), published only on the server's loopback address, port 8088. Nothing is reachable from outside until you add the access gate in step 5. The app has no login of its own.

## 1. Pre-checks (read-only, on the server)
- `docker --version && docker compose version`
- `ss -ltn | grep 8088` returns nothing. If it is taken, set `COUNCIL_WEB_PORT` to another free port in the environment and use that port everywhere below.
- Decide how traffic gets in: Cloudflare Tunnel (recommended, touches no nginx) or an nginx server block (step 4b).

## 2. Put the code on the server
```bash
sudo mkdir -p /opt/llm-council && sudo chown "$USER" /opt/llm-council
git clone https://github.com/Shimon2626/llm-council.git /opt/llm-council
cd /opt/llm-council
```

## 3. Keys and start
```bash
cp .env.example .env && chmod 600 .env
# edit .env: OPENROUTER_API_KEY (required), NVIDIA_API_KEY (optional).
# Use keys for this app only; do not reuse another system's .env.
docker compose up -d --build
docker compose ps                     # both services Up
curl -s http://127.0.0.1:8088/api/models | head -c 200
```
Conversations live in the Docker volume `llm-council_council-data`. All users share one history and one OpenRouter balance.

## 4a. Expose with Cloudflare Tunnel (recommended)
In Cloudflare Zero Trust, Networks, Tunnels: create or reuse a tunnel and add a public hostname `council.<your-domain>` whose service URL is `http://127.0.0.1:8088`.

## 4b. Or expose with nginx
Add a separate server block (do not edit shared route files) proxying `council.<your-domain>` to the same loopback address and port, with `proxy_buffering off;` and `proxy_read_timeout 900s;`, then run `nginx -t` and reload nginx. With this route, firewall port 80 to Cloudflare IP ranges only.

## 5. Access gate (do this before telling anyone the URL)
Zero Trust, Access, Applications, Add, Self-hosted: domain `council.<your-domain>`; policy Allow = your team's emails or company email domain; one-time PIN login is enough.

## 6. Verify
- A private browser window to `https://council.<your-domain>` shows the Access login, not the app.
- After login the UI loads and the model picker lists models.
- Run one short council question end to end.

## Updating
```bash
cd /opt/llm-council && git pull && docker compose up -d --build
```

## Rollback
`docker compose down` (add `-v` to also delete conversations), remove the tunnel hostname or nginx block, delete the Access application.
