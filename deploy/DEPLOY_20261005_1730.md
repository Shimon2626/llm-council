# LLM Council — hosting runbook (VPS + Cloudflare Access)

Not yet executed. Written for the operator (or a session explicitly authorized to write to the VPS).

## 1. Pre-checks (read-only)
- `ss -ltnp | grep 8001` — if taken, pick another port and edit both files in this folder.
- Confirm the Cloudflare zone for smarketsherpa.ai and how existing subdomains reach the VPS (proxied A record vs tunnel).

## 2. Install (on the VPS, as root)
1. `useradd -r -m council`; copy this repo to `/opt/llm-council` (exclude `.venv`, `frontend/node_modules`, `.env`, `data/`).
2. `cd /opt/llm-council && uv sync` (creates `.venv`). Build the UI locally with `npm run build` and copy `frontend/dist/`, or build on the VPS.
3. Create `/opt/llm-council/.env` (mode 600, owner council) with OPENROUTER_API_KEY and NVIDIA_API_KEY only. Do NOT reuse the shared RevFlow .env.
4. `mkdir -p /opt/llm-council/data/conversations && chown -R council: /opt/llm-council/data`
5. Install the service file as `llm-council.service`; `systemctl daemon-reload && systemctl enable --now llm-council`.
6. Install the nginx conf as `/etc/nginx/conf.d/llm-council.conf`; `nginx -t && systemctl reload nginx`.

## 3. Cloudflare
- DNS: `council` record for smarketsherpa.ai, proxied (orange cloud), pointing at the VPS (or add a tunnel hostname).
- Zero Trust > Access > Applications > Add > Self-hosted: domain `council.smarketsherpa.ai`; policy Allow = your team's emails (or the company email domain); one-time PIN login is enough.
- Firewall the VPS so port 80 accepts only Cloudflare IP ranges, otherwise Access can be bypassed by hitting the VPS IP directly.

## 4. Verify
- `curl -s localhost:8001/` on the VPS returns `{"status":"ok",...}`.
- Browser to https://council.smarketsherpa.ai: Access login appears, then the UI; model picker lists Kimi K3.
- Anonymous request without Access login is rejected.

## Notes
- All users share one conversation store and one OpenRouter balance.
- Rollback: `systemctl disable --now llm-council`, delete the nginx conf, delete the Access app.
